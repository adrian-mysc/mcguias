O que é o Book de Layout?

MCD-075

O Book de Layout (MCD-075) é o manual oficial de organização do restaurante McDonald's. Define o posicionamento correto de equipamentos, utensílios e insumos em cada área operacional.

💡
Objetivo principal: Melhorar a organização para facilitar o trabalho dos funcionários, priorizando tempos, movimentos e ergonomia.
🏗️

Princípios do Layout

1
Tempos: Reduzir o tempo de deslocamento e busca por itens durante o serviço
2
Movimentos: Minimizar movimentos desnecessários — cada item deve estar onde é usado
3
Ergonomia: Posicionar itens de forma que evitem esforço excessivo ou posturas inadequadas
4
Adaptação: Quando a estrutura do restaurante não permitir o layout exato, seguir o mais próximo possível dos layouts propostos
